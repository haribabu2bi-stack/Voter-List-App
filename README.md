# Voter List Manager

Voter List Manager అనేది ఓటర్ల వివరాలను నిర్వహించుకోవడానికి ఒక ఆఫ్‌లైన్ వెబ్ అప్లికేషన్ (Offline Web Application).

## ఫీచర్లు (Features)
- **ఓటర్ల సెర్చ్ & ఫిల్టర్లు**: పేరు, ఇంటిపేరు, మొబైల్ నంబరు, Voter ID ద్వారా సులభంగా వెతకవచ్చు.
- **ఇంటిపేరు & కులం ఫిల్టర్లు**: నిర్దిష్ట ఇంటిపేరు లేదా కులానికి సంబంధించిన ఓటర్ల జాబితాను వేరు చేసి చూడవచ్చు.
- **కొత్త ఓటరు నమోదు / ఎడిట్**: కొత్త వివరాలను జతచేయడం లేదా ఉన్న వివరాలను సవరించడం సాధ్యమవుతుంది.
- **డేటా ఎగుమతి (Export)**: ఓటర్ల వివరాలను Excel / CSV రూపంలో డౌన్‌లోడ్ చేసుకోవచ్చు.
- **బ్యాకప్ & రీస్టోర్ (Backup & Restore)**: మీ డేటాను JSON ఫైల్‌గా భద్రపరుచుకోవచ్చు మరియు అవసరమైనప్పుడు రీస్టోర్ చేయవచ్చు.

## ఫైళ్ళ వివరాలు (Files)
1. `index.html` - అప్లికేషన్ యొక్క HTML, CSS మరియు JavaScript కోడ్ అలాగే ప్రాథమిక ఓటర్ల డేటా.
2. `README.md` - ప్రాజెక్ట్ వివరాలు మరియు ఉపయోగించే విధానం.

## ఉపయోగించే విధానం (How to Use)
1. `index.html` ఫైల్‌ను మీ మొబైల్ లేదా కంప్యూటర్ బ్రౌజర్‌లో ఓపెన్ చేయండి.
2. డేటా మీ బ్రౌజర్ యొక్క local storage లో సేవ్ అవుతుంది.
3. ఫోన్ లేదా బ్రౌజర్ డేటా క్లియర్ చేసే ముందు 'Backup Save' బటన్ ద్వారా బ్యాకప్ తీసుకోవడం మంచిది.
