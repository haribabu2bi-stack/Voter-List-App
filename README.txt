Voter List Web App — GitHub Pages update

This package contains index.html with the voter records from the uploaded "Voter List.xlsx".

Update your existing GitHub Pages repository:
1. Open your voter-list-app repository.
2. Open the existing index.html and choose the pencil/Edit icon, or upload this new index.html to the repository root and replace the old file.
3. Commit changes.
4. Wait for GitHub Pages deployment to finish, then open the website and hard-refresh (Ctrl+Shift+R).

Important:
- This is the current static GitHub Pages version. It displays the data embedded in index.html.
- Updating the Excel file later requires generating and uploading a new index.html again.
- The app uses a new browser storage key so old locally cached records from the prior version won't override the new initial data.
- This voter list contains personal information. Do not publish/share it publicly unless you have permission and understand that anyone with the public link may be able to access it.
