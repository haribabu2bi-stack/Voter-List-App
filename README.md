# 🗳️ Ward 19 Voter List Manager (ఓటర్ల జాబితా మేనేజర్)

ఈ ప్రాజెక్ట్ **వార్డ్ 19 ఓటర్ల సమాచారాన్ని (Voter List)** సులభంగా నిర్వహించడానికి, సెర్చ్ (Search) చేయడానికి మరియు ఎడిట్ చేయడానికి తయారు చేసిన వెబ్ అప్లికేషన్ / మేనేజ్‌మెంట్ సిస్టమ్.

---

## 📊 ఫైల్ వివరాలు (Data Overview)

- **మూల ఫైల్:** `voter_list_ward19 27.10.26.xlsx`
- **మొత్తం రికార్డులు:** 1,326 ఓటర్ల వివరాలు
- **కాలమ్స్ (Columns):**
  1. `S.No` - వరుస సంఖ్య
  2. `MOBILE` - మొబైల్ సంఖ్య
  3. `SECOND` - ప్రత్యామ్నాయ ఫోన్ సంఖ్య
  4. `పేరు` - ఓటరు పేరు (తెలుగులో)
  5. `తండ్రి / భర్త` - తండ్రి లేదా భర్త పేరు
  6. `Gender` - లింగం (Male / Female)
  7. `Age` - వయస్సు
  8. `Voter ID` - ఓటర్ కార్డ్ నంబర్ (EPIC No)
  9. `INTIAL` - ఇంటిపేరు (ఇంగ్లీషులో)
  10. `CASTE` - కులం వివరాలు
  11. `Death` - మరణించిన వారి స్థితి (DEATH / Active)

## 🚀 వినియోగించే విధానం (How to Use)

### 1. కంప్యూటర్ లేదా మొబైల్‌లో ఓపెన్ చేయడం:
- `voter_list_ward19_project.zip` ఫైల్‌ను Extract / Unzip చేయండి.
- అందులో ఉన్న `index.html` పై క్లిక్ చేసి Chrome లేదా ఏదైనా బ్రౌజర్‌లో ఓపెన్ చేయండి.

### 2. ఫీచర్లు (Features):
- 🔍 **సెర్చ్ (Search):** పేరు, ఓటర్ ID, మొబైల్ నంబర్ లేదా కులం (Caste) ఆధారంగా వెంటనే రికార్డులను వెతకవచ్చు.
- ➕ **కొత్త ఓటరును జత చేయడం (Add New Voter):** కొత్త ఓటరు సమాచారాన్ని యాప్‌లోకి జోడించవచ్చు.
- ✏️ **సవరణ (Edit / Update):** మార్పులు ఉంటే ఓటరు వివరాలను ఎడిట్ చేయవచ్చు.
- 💾 **బ్యాకప్ & రీస్టోర్ (Backup & Restore):** సమాచారం పోకుండా JSON ఫైల్ ద్వారా బ్యాకప్ తీసుకోవచ్చు.
- 📤 **ఎక్సెల్ / CSV ఎగుమతి (Export to Excel/CSV):** సమాచారాన్ని ఒకే క్లిక్‌తో CSV రూపంలో డౌన్‌లోడ్ చేసుకోవచ్చు.
