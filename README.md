# Ward 19 Voter List Interactive Directory

ఈ ప్రాజెక్ట్ `voter_list_ward19 27.10.26_920PM.xlsx` ఎక్సెల్ ఫైల్ ఆధారంగా తయారు చేయబడింది. ఇందులో 1,326 కంటే ఎక్కువ ఓటర్ల వివరాలను సులభంగా శోధించడం (Search) మరియు ఫిల్టర్ చేయడం కోసం డిజైన్ చేయబడింది.

## ఫీచర్లు (Features)

1. **రెండు వీక్షణ మోడ్‌లు (Dual View Modes):**
   - **List View (జాబితా వీక్షణ):** క్లాసిక్ టేబుల్ రూపంలో డేటా సులభంగా చూసే సదుపాయం.
   - **Grid View (గ్రిడ్ వీక్షణ):** రెస్పాన్సివ్ కార్డ్ డిజైన్ ద్వారా మొబైల్‌లో సులభంగా చూసే సదుపాయం.

2. **లైవ్ శోధన (Live Search):**
   - పేరు (Name), తండ్రి/భర్త పేరు, Voter ID, కులం (Caste), లేదా మొబైల్ నంబర్ టైప్ చేయగానే రియల్-టైమ్‌లో ఫిల్టర్ అవుతుంది.

3. **లింగ ప్రాతిపదికన ఫిల్టర్ (Gender Filter):**
   - పురుషులు (Male) మరియు మహిళలు (Female) వివరాలను వేర్వేరుగా చూడవచ్చు.

## ఫైళ్ల జాబితా (Files Included)

- `index.html`: ప్రధాన డిజిటల్ పోర్టల్ (HTML, Tailwind CSS, JavaScript).
- `README.md`: ప్రాజెక్ట్ గైడ్ మరియు వివరణ.

## ఉపయోగించే విధానం (How to Use)

1. `index.html` ఫైల్‌ను ఏదేని వెబ్ బ్రౌజర్ (Google Chrome, Edge, Mobile Browser) లో ఓపెన్ చేయండి.
2. Search Box లో పేరు లేదా Voter ID ఎంటర్ చేసి వెతకండి.
3. పైన కుడి వైపు ఉన్న **List View** మరియు **Grid View** బటన్లను ఉపయోగించి వీక్షణను మార్చుకోండి.
